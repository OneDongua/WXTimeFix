# WXTimeFix - 微信图片时间修复

<img src="/app/src/main/res/drawable/icon.png" alt="图标" width="256" height="256" />

## 📱 项目简介

WXTimeFix 是一款 Android 应用，用于修复微信导出图片的修改时间问题。
微信导出的图片文件名包含保存时的时间戳（如 `mmexport1781149514191.jpg`
），但备份恢复后很可能失去文件修改日期属性，导致图片在相册中的时间线上位置错误。
本应用可以从文件名中提取时间戳，并恢复文件的修改时间。

[下载(Releases)](https://github.com/OneDongua/WXTimeFix/releases)

若想恢复系统相机拍摄的照片时间，推荐使用[照片时间修复](https://github.com/Cryolitia/PhotoTimeFix/tree/a0911c6958805bf39b789cc2af48b0581fa876b4) ([这里下载](https://github.com/Cryolitia/PhotoTimeFix/releases/tag/3.4))

## ✨ 功能特性

- 🔍 **智能识别**：自动识别 `mmexport{时间戳}.{后缀}` 和 `wx_camera_{时间戳}.{后缀}` 格式的文件
- ⏱️ **批量修复**：支持批量修改文件时间戳，可自定义时间范围
- 📊 **统计数量**：显示匹配的文件数量
- 💾 **自动保存**：自动保存路径和时间范围设置
- 🔄 **媒体库刷新**：一键刷新系统媒体库，让相册立即显示正确的日期
- 🎨 **简洁界面**：Material Design 2 风格，支持深色模式

## 📋 系统要求

- Android 7 (API 24) 及以上
- 存储权限（Android 10 及以下）或所有文件访问权限（Android 11 及以上）

## 🚀 使用方法

### 1. 授予权限

首次启动应用时，需要授予存储权限：

- **Android 11+**：需要"所有文件访问权限"，初次启动自动跳转
- **Android 10 及以下**：需要读写存储权限，弹窗允许即可

### 2. 选择目录

点击"选择路径"按钮，选择包含微信图片的目录（默认为 `/sdcard/Pictures/Weixin`）

### 3. 设置时间范围（可选）

- **起始位置**：要处理的最小时间戳（留空则自动使用最小值）
- **终止位置**：要处理的最大时间戳（留空则自动使用最大值）

### 4. 开始修复

点击"开始修复"按钮，应用将：

1. 扫描目录下所有匹配的文件
2. 从文件名中提取时间戳
3. 设置文件的修改时间为对应的时间戳
4. 显示处理结果

### 5. 刷新媒体库

点击"刷新媒体库"按钮，发送媒体扫描广播，让系统相册更新文件日期信息 (部分系统相册无效)

## 📁 支持的文件格式

- `mmexport{13位毫秒时间戳}.{扩展名}`
    - 例如：`mmexport1609459200000.jpg`

- `wx_camera_{13位毫秒时间戳}.{扩展名}`
    - 例如：`wx_camera_1609459200000.png`

## 🔧 技术实现

### 核心功能

- **URI 路径转换**：支持从 SAF (Storage Access Framework) URI 获取真实文件路径
- **正则表达式匹配**：精确匹配微信导出文件名格式
- **多线程处理**：使用线程池并行处理文件，提升性能
- **SharedPreferences**：持久化保存用户设置

### 主要类说明

- **MainActivity**：主界面和业务逻辑
- **FileUtils**：URI 到文件路径的转换工具类

## 📝 注意事项

1. **备份重要数据**：虽然本应用只修改文件时间戳，并没有任何读取/删除操作，但建议操作前备份重要文件
2. **权限要求**：Android 11+ 必须授予"所有文件访问权限"才能正常工作
3. **时间戳格式**：仅支持 13 位毫秒时间戳格式
4. **媒体库刷新**：部分设备可能需要清除相册数据才能看到更新日期，注意检查最近删除是否有重要图片，以免被一并清除
